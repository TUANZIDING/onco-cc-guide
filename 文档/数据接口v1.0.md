# 数据接口说明 v1.0 · Data access

OnCo的全部记录可通过网站、静态API、命令行和MCP四种方式访问，无需密钥。每种方式都附带同一署名：`Data from OnCo (onco.cc), CC BY-NC 4.0; commercial use needs a licence`。核对日期：2026-10-19。

[返回首页](../README.md) · [English homepage](英文说明v1.0.md)

## 静态JSON API

接口根目录：`https://onco.cc/api/v1/`，说明页 [onco.cc/api](https://onco.cc/api/)，完整描述见 [OpenAPI 3.1](https://onco.cc/api/v1/openapi.json)。

| 文件 | 内容 |
| --- | --- |
| [`meta.json`](https://onco.cc/api/v1/meta.json) | 构建日期、版本、各类对象计数、文件清单 |
| `<复数类名>.json` / `.csv` | 某一类全部记录，例如 [`drugs.json`](https://onco.cc/api/v1/drugs.json) |
| `entities/<id>.json` | 单个对象及其按类分组的相邻对象，例如 [`entities/tnbc.json`](https://onco.cc/api/v1/entities/tnbc.json) |
| [`search.json`](https://onco.cc/api/v1/search.json) | 精简检索文档（id、类型、名称、别名、TL;DR、标签、网页路由） |
| `context/<id>.md` | 每个对象一份Markdown上下文，适合给语言模型阅读 |
| `all.json` / `all.ndjson` | 全库下载 |
| [`schema.json`](https://onco.cc/api/v1/schema.json) | 单个对象的JSON Schema |

给语言模型的入口：[`llms.txt`](https://onco.cc/llms.txt)。

本仓库示例：

```sh
python3 示例/检索示例v1.0.py radiation 30
```

## 命令行与MCP

官方仓库 `packages/` 中有命令行工具 `onco-cli` 和MCP服务器 `onco-mcp`（工具：`search`、`get_entity`、`list_kind`、`ask`、`context`、`compare`）。

> 2026-10-19核对：npm上名为 `onco` 的包不是OnCo的工具，`onco-mcp` 尚未在npm发布。因此请从源码构建，不要直接运行 `npx onco`。

```sh
git clone https://github.com/judegomila/OnCo.git
cd OnCo
npm ci
npm run cli:build    # 生成 packages/onco-cli/dist/onco.mjs
npm run mcp:build    # 生成 packages/onco-mcp/dist/onco-mcp.mjs
node packages/onco-cli/dist/onco.mjs search "HER2-low breast cancer" --kind drug
claude mcp add onco -- node "$PWD/packages/onco-mcp/dist/onco-mcp.mjs"
```

完整说明见官方 [docs/ACCESS.md](https://github.com/judegomila/OnCo/blob/main/docs/ACCESS.md)。

## 使用边界

- 数据适用CC BY-NC 4.0：个人与教育用途免费，须署名并链接 https://onco.cc；商业使用须联系OnCo授权（[licence](https://onco.cc/about/#licence)）。
- 内容仍在建设中，可能不完整或有误；不是医学建议，使用前回到原始来源核实。
